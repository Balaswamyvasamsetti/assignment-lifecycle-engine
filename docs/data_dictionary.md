# Data Dictionary: Assignment Lifecycle & Grading Engine

This document defines the schema, data types, primary and foreign key constraints, field descriptions, allowable value domains, and sample data for all entities generated by the synthetic lifecycle generator.

---

## 1. Course (`courses.csv`)
Represents an academic course offering within a specified academic term and department.

- **Primary Key**: `course_id` (Pattern: `CRS-2026-XXXXXX`, e.g., `CRS-2026-000001`)
- **Foreign Keys**: None

| Field Name | Type | Nullable | Constraints / Enum | Description | Sample Value |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `course_id` | `TEXT` | No | PK, Regex: `^CRS-2026-\d{6}$` | Unique zero-padded course identifier | `CRS-2026-000001` |
| `title` | `TEXT` | No | Unique per offering | Descriptive course name with section number | `Distributed Systems (Sec 01)` |
| `department` | `TEXT` | No | `Computer Science`, `Data Science`, `Electrical Engineering`, `Mathematics`, `Mechanical Engineering`, `Information Systems`, `Bioinformatics`, `Economics` | Academic department offering the course | `Computer Science` |
| `term` | `TEXT` | No | `Fall 2026`, `Spring 2026` | Academic term | `Fall 2026` |
| `start_date_utc`| `TEXT` | No | ISO 8601 UTC (`YYYY-MM-DDTHH:MM:SSZ`) | Term start timestamp | `2026-08-25T00:00:00Z` |
| `end_date_utc` | `TEXT` | No | ISO 8601 UTC (`> start_date_utc`) | Term conclusion timestamp | `2026-12-20T23:59:59Z` |
| `status` | `TEXT` | No | `ACTIVE`, `ARCHIVED` | Current lifecycle status of the course | `ACTIVE` |

## 3. Enrollment (`enrollments.csv`)
Associates a learner with a specific course offering.

- **Primary Key**: `enrollment_id` (Pattern: `ENR-2026-XXXXXX`)
- **Foreign Keys**:
  - `course_id` $\rightarrow$ `Course.course_id`
  - `learner_id` $\rightarrow$ `Learner.learner_id`
- **Unique Constraint**: Composite uniqueness on `(course_id, learner_id)`

| Field Name | Type | Nullable | Constraints / Enum | Description | Sample Value |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `enrollment_id` | `TEXT` | No | PK, Regex: `^ENR-2026-\d{6}$` | Unique enrollment record ID | `ENR-2026-000105` |
| `course_id` | `TEXT` | No | FK $\rightarrow$ `Course.course_id` | Enrolled course identifier | `CRS-2026-000001` |
| `learner_id` | `TEXT` | No | FK $\rightarrow$ `Learner.learner_id` | Enrolled student identifier | `LRN-2026-000042` |
| `enrolled_at_utc` | `TEXT` | No | ISO 8601 UTC | Timestamp student registered for course | `2026-08-10T14:30:00Z` |
| `status` | `TEXT` | No | `ACTIVE`, `DROPPED` | Course-level enrollment status | `ACTIVE` |

## 5. Rubric (`rubrics.csv`)

- **Primary Key**: `rubric_id` (Pattern: `RUB-<assignment_id>-01`)
- **Foreign Keys**:
  - `assignment_id` $\rightarrow$ `Assignment.assignment_id` (Unique 1:1)

| Field Name | Type | Nullable | Constraints / Enum | Description | Sample Value |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `rubric_id` | `TEXT` | No | PK, Regex: `^RUB-ASN-2026-\d{6}-\d{2}$` | Rubric identifier | `RUB-ASN-2026-000001-01` |
| `assignment_id` | `TEXT` | No | FK $\rightarrow$ `Assignment.assignment_id` | Parent assignment | `ASN-2026-000001` |
| `title` | `TEXT` | No | None | Rubric title | `Rubric: Assignment 1: Distributed Consensus` |
| `total_points` | `REAL` | No | Default: `100.0` | Total maximum attainable points | `100.0` |
| `version` | `INTEGER`| No | Default: `1` | Version number of the grading rubric | `1` |

- **Primary Key**: `submission_id` (Pattern: `SUB-<assignment_id>-<learner_id>-<version>`)
- **Foreign Keys**:
  - `assignment_id` $\rightarrow$ `Assignment.assignment_id`

| Field Name | Type | Nullable | Constraints / Enum | Description | Sample Value |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `submission_id` | `TEXT` | No | PK, Regex: `^SUB-ASN-2026-\d{6}-LRN-2026-\d{6}-\d{2}$`| Submission identifier | `SUB-ASN-2026-000001-LRN-2026-000042-01` |
| `assignment_id` | `TEXT` | No | FK $\rightarrow$ `Assignment.assignment_id` | Assignment submitted for | `ASN-2026-000001` |
| `learner_id` | `TEXT` | No | FK $\rightarrow$ `Learner.learner_id` | Submitting student | `LRN-2026-000042` |

| `status` | `TEXT` | No | `SUBMITTED`, `GRADED`, `APPEALED`, `RESUBMITTED` | Submission lifecycle state | `GRADED` |

- **Primary Key**: `grade_id` (Pattern: `GRD-<submission_id>`)
- **Foreign Keys**:
  - `submission_id` $\rightarrow$ `Submission.submission_id` (Unique 1:1)

| Field Name | Type | Nullable | Constraints / Enum | Description | Sample Value |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `grade_id` | `TEXT` | No | PK, Regex: `^GRD-SUB-.*` | Unique grade record identifier | `GRD-SUB-ASN-2026-000001-LRN-2026-000042-01` |
| `submission_id` | `TEXT` | No | FK $\rightarrow$ `Submission.submission_id` | Associated submission | `SUB-ASN-2026-000001-LRN-2026-000042-01` |
| `raw_score` | `REAL` | No | $\sum \text{feedback.points}$ | Sum of criterion scores before penalties | `92.50` |

| `graded_by` | `TEXT` | No | Instructor identifier | Instructor/TA who evaluated work | `INST-2026-000012` |
| `graded_at_utc` | `TEXT` | No | ISO 8601 UTC ($> \text{submitted}$) | Timestamp grade was posted | `2026-10-17T11:45:00Z` |
